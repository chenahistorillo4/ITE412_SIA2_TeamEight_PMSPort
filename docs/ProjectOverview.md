# Project Overview

## 1. System Objectives
The PMS Port Ferry Booking Management System aims to modernize the ticketing process for the Pinamalayan–Marinduque–Sibale route.  
It solves problems of long queues, manual booking errors, and inefficient scheduling by providing:  
- Online ticket booking to avoid long lines  
- Cashless payments via GCash  
- QR boarding passes for faster and safer boarding  
- An admin dashboard for trip, reservation, and payment management  
- Real-time notifications for passengers about trip confirmations, changes, or cancellations  

## 2. Proposed Scope
- **Passenger Services:** Online booking, QR boarding passes, booking history  
- **Payment Integration:** Secure GCash transactions, discount features for students/senior citizens  
- **Cargo Services:** Reservation for small goods (e.g., motorcycles, sacks of rice)  
- **Admin Dashboard:** Trip scheduling, passenger monitoring, payment tracking  
- **Out-of-Scope:** Bulk freight, hazardous materials, vessel maintenance, refunds/cancellations  

## 3. Stakeholders
- **Passengers** — Benefit from convenient booking, faster boarding, and cashless payments  
- **Port Staff** — Manage reservations, schedules, and payments more efficiently  
- **Ferry Owners** — Track tickets, monitor operations, and improve customer service   

## 4. Tools & Technologies
- **Frontend:** React.js (JSX, CSS, JavaScript)  
- **Backend/Database:** Firebase (authentication, cloud storage, real-time database)  
- **Design:** Figma for UI/UX prototyping  
- **Development Tools:** Visual Studio Code, Node.js  
- **Version Control:** Git/GitHub for collaboration  
- **Testing:** Unit testing and user feedback sessions
